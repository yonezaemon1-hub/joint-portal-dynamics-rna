# Third-party software and sources

This repository does **not** redistribute ViennaRNA binaries or source code. The Python environment installs ViennaRNA separately. ViennaRNA is governed by its own license and attribution requirements; consult the official ViennaRNA license before redistribution or commercial bundling.

The focal RNA system and comparator formulas are reproduced from and compared against Martin et al. (2024), whose public code and paper remain under their respective licenses. No third-party source repository is vendored here.

Primary third-party dependencies include NumPy, SciPy, and ViennaRNA; each remains under its own license.
